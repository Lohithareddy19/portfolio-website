# Personal Portfolio: Chamala Lohitha

Responsive, accessible portfolio built for FSD Assignment-1 (SPC0701CS) using HTML5, CSS3, Bootstrap 5, and JavaScript (ES6+).

## Features
- Semantic sections: Home, About, Education, Skills, Projects, Contact
- Mobile-first CSS with media queries, Flexbox, and Bootstrap grid, navbar, cards, buttons, forms, table, and alerts
- Interactive: project filtering, dark/light theme switch, rotating skill text
- Contact form with live client-side validation and success/error alerts
- Accessibility: skip link, labels, ARIA attributes, visible focus, reduced-motion support

## Run
Open `index.html` in a browser (internet needed for the Bootstrap and font CDNs).

## Structure
```
index.html   structure
style.css    custom styles
script.js    data rendering, filter, theme, validation
assets/      images
```
